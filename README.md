# Hospital Management System

This is a simple C++ console application for managing basic hospital operations. It allows users to add patient and doctor details, book appointments, and view records through a menu-driven interface.

## Features

* Add and manage patient details
* Add doctor information
* Book appointments
* View patient and doctor records
* Menu-driven interface

## Concepts Used

* Object-Oriented Programming (OOP)
* Classes and Objects
* STL

## Files

* `HospitalManagement.cpp` – Main source code

## How to Run

```bash
g++ HospitalManagement.cpp -o hospital
./hospital
```

* Using classes to organize code
